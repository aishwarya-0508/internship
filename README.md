# ShareSphere

## Smart Community Resource Sharing Platform

ShareSphere is a simple web application developed using HTML and CSS for sharing community resources like books, notes, devices and tools.

- Home Page
- Navigation Bar
- Resource Sharing Section
- Community Page
- About Page
- Contact Page
